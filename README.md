# 竞品主图优化工具

这个版本分两步：

1. 前端分析自己的主图和竞品图，生成模特、角度、背景、构图和卖点方案。
2. 本地后端调用 OpenAI `gpt-image-1.5` 图片编辑接口，生成真实商业图。

## 启动

最简单方式：双击 `start.bat` 启动服务，然后在网页右上角“设置”里填写中转站信息。

不想每次手动启动：双击 `install-autostart.bat` 一次，之后 Windows 登录后会自动启动。需要取消时双击 `remove-autostart.bat`。

中转站模式：

- API Key：填写中转站给你的 Key。
- API 地址：填写中转站地址，例如 `https://ai.t8star.cn`。工具会自动补成 OpenAI 兼容的 `/v1` 路径。
- 生图模型：填写中转站支持的图片模型，例如 `gpt-image-2`。
- LLM 模型：可选，先用于记录配置。
- 配置会保存到本机 `api-config.local.json`，重启服务后自动读取。

PowerShell:

```powershell
$env:OPENAI_API_KEY="你的 API Key"
node server.js
```

然后打开：

```text
http://127.0.0.1:4173
```

## 为什么要后端

API Key 不能放在浏览器前端，否则会被直接看到。`server.js` 只在本机运行，用来安全代理 OpenAI 图片生成请求。

## 输出逻辑

- GPT 分析结果负责确定：模特、产品角度、真实背景、光线、构图和禁忌项。
- `gpt-image-1.5` 负责真实生成图片。
- 中文卖点建议后续继续由前端 Canvas 添加，避免图片模型生成乱码中文。

## 主图对标优化

登录后从顶部进入「主图对标优化」。上传 1–4 张同款商品白底图、1 张竞品参考图，填写已核实的卖点。工具展示竞品优点、画面证据、推荐商品角度和一个可执行的改进点。支持选图、修改标题、检查抠图、生成参考版与改进版、手机缩略图对照、AI 复核、下载 PNG 和保存方案记录。选中的图片可存入「以图做图」历史。

- **视觉分析与复核**：管理员在原工具「设置」填写支持多张图片的聊天模型。OpenAI 官方 API 推荐 `gpt-5.4-mini`（`/v1/chat/completions`）。新功能空缺时使用这一分析模型名。
- **AI 背景和光影编辑**：官方 API 推荐 `gpt-image-2.6-sunburst`，需在原工具「设置」的生图模型字段选择。使用中转站时填该站实际支持的模型名，例如支持 `gpt-image-2` 时可填这个。新功能需要兼容 `/v1/images/generations`、`/v1/images/edits` 及 `data[0].b64_json` 返回格式。
- **实拍合成**：背景、图片和文字由浏览器 Canvas 合成。位置、标题和轮廓反差改动可复用同一个背景，不新增生图调用。AI 光影编辑可能改变商品细节，成图应与原图对照。该路径出现编辑错误会保留参考版，并显示失败原因。
- **素材**：优先用轮廓清楚的白底实拍或透明 PNG；纯白机身与纯白背景难以分离时使用透明 PNG。白底处理从边缘去除接近白色的连通区域。页面支持调节阈值和人工预览。
- **资费与保留**：真实模型调用使用站点配置的 API 额度。生成的参考版和改进版须下载或选择存入历史才会长期保留；方案记录由页面下载为 JSON。
